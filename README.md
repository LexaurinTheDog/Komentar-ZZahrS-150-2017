# Komentář k zákonu č. 150/2017 Sb., o zahraniční službě a o změně některých zákonů (zákon o zahraniční službě)

Otevřený komentář k zákonu o zahraniční službě — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; zastupitelské úřady, výkon zahraniční a konzulární služby, konzulární ochrana, služební a pracovněprávní vztahy, systemizace a platové náležitosti.

Konsolidované znění: dokument e-Sbírky `SB-2017-00150_2025-12-09`.
